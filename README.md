# CarSec

CarSec is an Android application developed as a collaborative university project focused on vehicle security and user account management.

The project was built using **Java** and **Android Studio**, with a team-based development workflow. My contributions focused primarily on implementing user authentication functionality and improving the application's user interface.

## Features

- User account login
- Google Sign-In authentication
- User-facing Android UI
- Navigation between application screens
- Integration of authentication functionality with the application interface

## Technologies

- **Java**
- **Android Studio**
- **Gradle**
- **Android SDK**
- **Google Sign-In**

## Getting Started

### Prerequisites

To build and run the project, you will need:

- Android Studio
- Android SDK
- Java/JDK compatible with the project's Gradle configuration
- An Android emulator or physical Android device

### Installation

1. Clone the repository:

```bash
git clone https://github.com/JFBStorm/CarSec.git
```

2. Open the project in **Android Studio**.

3. Allow Android Studio to synchronize the Gradle project and download any required dependencies.

4. Configure an Android emulator or connect a compatible Android device.

5. Build and run the application through Android Studio.
